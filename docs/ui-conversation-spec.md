# 《灰环点火》科幻会话 UI 规格

## 1. 视觉方向

采用 **HUD / Sci-Fi FUI**：黑蓝背景、冷青主色、紫色状态层、洋红色警告，保留细线、刻度、扫描和数据标签，但把霓虹限制在交互重点，避免满屏发光造成信息噪声。

### 色彩令牌

```css
:root {
  --bg: #050510;
  --surface: #101823;
  --surface-2: #151f2e;
  --text: #e0e0ff;
  --muted: #94a3b8;
  --border: #333344;
  --cyan: #00ffff;
  --violet: #7b61ff;
  --magenta: #ff00ff;
  --danger: #ef4444;
  --success: #42d392;
  --focus: #9ffcff;
}
```

标题和英文代号可用 Orbitron；中文正文使用 `Noto Sans SC, Microsoft YaHei, sans-serif`；数字和资源值使用 `JetBrains Mono, Consolas, monospace`。字体必须提供本地回退，离线包不能依赖运行时 Google Fonts 请求。

## 2. 页面结构

### 桌面端（≥1024px）

```text
┌──────────────────────────────────────────────────────────────┐
│ 频道 / 任务倒计时 / 警报等级 / 当前场景                      │
├──────────────────────────────┬───────────────────────────────┤
│                              │  Three.js 态势窗                │
│  对话时间线                   │  - 地形与路线                  │
│  角色头像 / 频道标签          │  - 车队 / 维修节点              │
│  潜台词式对白                 │  - 坡度 / 距离 / 温度 / 风速     │
│                              │  - 通信置信度                  │
├──────────────────────────────┴───────────────────────────────┤
│ 资源条：时间 能源 物资 人员 安全 | 因果日志                    │
├──────────────────────────────────────────────────────────────┤
│ 选项卡 / 资源拖分配 / 预估变化 / [确认执行]                    │
└──────────────────────────────────────────────────────────────┘
```

### 手机端（<768px）

对话占满主视区，态势窗降为可展开的底部抽屉；资源条固定在顶部但只显示数值与趋势箭头，点击资源可打开详细说明。行动选项按整行按钮排列，不使用仅靠颜色区分的迷你芯片。

### 三个断点

* 375px：对话气泡最大宽度 92%，选项按钮高度至少 48px，态势窗默认折叠。
* 768px：对话与态势窗上下分栏，资源条变为两行。
* 1024px 以上：对话/态势窗左右分栏，显示完整因果日志和路线图例。

## 3. 组件与交互状态

* **频道头部**：显示 `现场链路 / 塔区值守 / 无人机`，离线时显示“延迟数据”并给出最后更新时间。
* **对白气泡**：头像、角色名、频道、短文本、可选的动作节拍；系统消息与角色消息使用不同边框语义。
* **行动卡**：显示意图、资源代价、风险区间、信息可信度和已满足的前置条件。卡片必须是原生 `<button>` 或可访问的按钮组，不使用可点击 `div`。
* **预估面板**：选择路线或资源分配后，用“当前 → 预计”显示时间、能源、物资、人员和安全的变化，并标明不确定范围。
* **执行状态**：确认后锁定选项，显示车辆移动、无人机探测、冷却管线或推进腔对齐的短动画；动画结束才进入反馈对白。
* **因果日志**：用箭头链记录“选择 → 直接变化 → 后续后果”，结算页可完整回放。
* **失败/重试**：资源不足时解释缺口并给出可回退的上一步；真正不可逆的结局提供“同种子重试”和“新参数重试”。

## 4. Three.js 态势窗

* 程序化高度场生成冰原、裂谷、地热沟和塔区；路线节点使用可点击的线段和标记球。
* 点击节点时显示坡度、距离、温度、风速、地表承载力和通信置信度；这些指标同时写入行动卡的预估公式。
* 车辆沿路线插值移动；锚索、无人机、中继和冷却管线用简单几何体表现，不依赖外部模型或运行时网络。
* 使用 `ResizeObserver` 监听画布容器，根据 `canvas.clientWidth/clientHeight` 更新渲染器和相机，不直接使用窗口尺寸。
* 使用 `Raycaster` 时把触点转换为 NDC，并对鼠标和触摸事件共用同一套选择逻辑；触摸拖拽不能阻塞页面滚动。
* HUD 叠加层使用 `MeshBasicMaterial` 或 HTML/CSS，实体设备才使用需要光照的材质；场景不可见时暂停循环动画。
* `WebGL` 不可用时切换为同一数据模型驱动的 2D SVG/Canvas 线路图，保证对话和策略仍可完成。

## 5. 动效与可访问性

* 关键状态变化使用 250–450ms 的淡入、描边或数据滚动；装饰性扫描线不能无限循环。
* `prefers-reduced-motion: reduce` 时直接呈现最终状态，保留资源数值和因果日志。
* 所有按钮和选项支持 Tab、Enter/Space、方向键选择；焦点环至少 2px、对比度清晰，并确保不被固定底栏遮挡。
* 新对话使用 `aria-live="polite"`，警报使用更明确的状态文本；图标使用 SVG，装饰图标 `aria-hidden="true"`，独立图标按钮有可读名称。
* 触控目标建议 48px 高，选项之间至少 8px 间距；不把色彩作为唯一语义，资源同时显示图标、文字和趋势。

## 6. 会话操作示例

1. 沈葵发来“芯温缺一段记录”。
2. 玩家点开态势窗的运输舱节点，查看温度曲线与扫描可信度。
3. 选择“暂停扫描”后，行动卡显示 `时间 -8`、校准可信度上升、车队安全不变。
4. 玩家点“确认执行”；Three.js 中扫描环扫过运输舱，资源条更新。
5. 因果日志出现“扫描耗时 8 分钟 → 南坡校准窗口缩短 → 裴衡要求改走西线”。
6. 下一段对白根据结果改变，不是播放预先写死的同一句话。



## 当前实现补充（0.1.0）

当前版本同时提供可展开手机态势窗、文字路线按钮、保障能源/负责人分配、风险预估、队员反馈、暂停/help dialog、localStorage 刷新恢复与结算记录下载。地图离屏时停止 WebGL 帧循环。三维模型和解码器全部本地打包，资产许可见 public/assets/LICENSES.md。
