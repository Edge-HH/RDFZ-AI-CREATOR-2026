# 灰环点火 · 对话推进 UI

设计依据：技能检索未找到直接匹配逐句剧情的条目；本次采用常规的主任务聚焦、逐步披露和单一主操作原则，未将未匹配的检索结果作为设计依据。

## 主屏层级

主屏始终优先显示：主线“送达点火芯，重启环弧—7” → 当前具体任务 → 正在说的话 → 当前唯一主要操作。顶部保留任务窗口与简要能源；暂停与菜单是辅助操作。

不同时铺开遥测、地图、因果日志和所有行动参数。主屏只保留最近两句通信，当前一句使用较大字号；完整历史在“通信记录”。

## 推进流程

简报 → 本段第一句 → 继续对话逐句揭示 → 队员提出问题 → 选择林岑的回应 → 预览代价 → 确认行动 → 队员回传与实际变化 → 继续剧情 → 下一项任务。

- 对白未读完，回应卡和确认按钮不出现，规则引擎也拒绝提前选择或执行。
- 选中后收起其他回应，仅展示当前回应、代价、风险和确认按钮。“重新选择”返回选项，无资源支出。
- 保障能源和负责人默认折叠；展开后仍可改变风险与专业效果。
- 选择路线回应自动同步地图节点，地图用于核验，而不是必经的页面切换。
- 每个选择有具体的角色回应和行动回传。险情的人员与时间损失追加到回传中，成功回传不能掩盖损失。

## 按需打开的面板

态势图：Three.js / 二维回退、路线节点、环境科学信息、视角控制。
资源与队员：时间、能源、物资、安全、稳定度、信任、健康和疲劳，以及维修日志。
通信记录：已完成任务的完整对白、林岑的回应和队员结果反馈。

使用原生 dialog 保持键盘焦点；关闭后回到原工具按钮。地图首次打开才初始化渲染器，收起、后台与暂停停止渲染。

## 手机与无障碍

单列对话布局；主要操作触控高度至少 48px，长回应自然换行。无需横向查看资源栏。辅助面板适应 375px 宽度与横屏，页面可纵向滚动，避免固定元素遮挡。

消息使用 aria-live，所有选择支持键盘；减少动态效果不改变规则。保存版本 2 存储逐句进度，兼容原版本存档；刷新不会跳到后续对白或重复扣除资源。
