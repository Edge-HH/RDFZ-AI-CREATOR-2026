# 0001 Luna 采用规则驱动的离线模型，规则引擎为纯函数

## 状态

已采纳（2026-10-06）

## 背景

作品需要可离线运行、不依赖私有 API 与在线大模型、不收集个人信息，并且“同一局可复盘、可测试”。Luna 的干预必须实际影响数值与结局，而不只是显示文字。

## 决定

1. Luna 是一个确定性的效用模型（`src/engine/luna.ts`）：对每个方案计算期望效果，资源采用边际递减价值并带损失厌恶，勘测权重随剩余时间上升，安全阈值以下重罚。**效用函数中刻意不包含“人类自主性”**，这是玩家与 Luna 的核心张力。台词为预写文本（`src/data/luna.json`）。
2. 规则引擎是纯 reducer：`act(state, action) → newState`，不修改输入、不依赖 DOM。随机数（mulberry32）状态保存在游戏状态中，因此 `replay(seed, actions)` 可完整复盘。
3. 剧情与数值放在静态 JSON 与 `rules.ts` 中，便于平衡调整与在文档中逐项披露为“游戏参数”。

## 后果

- 可以用模拟玩家策略在测试中证明三档结局均可触发、Luna 干预改变数值。
- Luna 的“智能”有限、可解释；其推荐依据可以逐条展示给玩家。
- 若将来接入在线模型，只能作为可选的台词润色层，不能替代规则判定，否则会破坏可复盘性。
