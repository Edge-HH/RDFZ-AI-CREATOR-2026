> 赛道：2026 校园 AI 创作者大赛 · 项目 3 策略游戏 · 时代征程【未来推演】

## Context

比赛要求做一款**以具有科学依据的未来任务为背景**的策略叙事游戏：玩家在时间、能源、物资、人员、安全五类限制下做资源配置、方案选择和风险判断，每个选择都必须对任务进度、环境或团队状态产生实际影响；要有开始、推进、反馈、结算、重新挑战的完整闭环；不能要求注册，不能依赖私有 API，并且要响应式。

经过 grilling 访谈敲定了以下设计：**玩家是地球飞控总师，指挥 2035 年中国主导的国际首次载人火星任务**。核心体验是**"光速之隔"**：你看到的遥测永远是 N 分钟前的火星，所以只能靠预案和授权去信任远方的乘员。仓库 main 分支已清空，从零开始；**不读取、不参考任何旧方案**（旧分支、`dist/`、`releases/` 等一律不打开）。

工作名：**《光速之隔》**（备选：《燧火》）。任务名：**燧火计划 · 祝融一号载人任务**。

## 2. 核心玩法系统

### 2.1 状态模型（纯 TypeScript，与渲染无关）
```
MissionState {
  chapter, step, missionDay, sol, seed, mode
  time:    { windowCountdown, launchSlipDays }
  energy:  { capacityKW, storageKWh, source: 'fission'|'solar'|'hybrid' }
  supplies:{ o2Days, waterDays, foodDays, spares }          // 用"可维持天数"表示，直观
  crew[4]: { id, health, morale, trust, dose_mSv, status }  // status: ok/injured/lost/stayed
  safety:  { systems, habitatIntegrity }
  science: number                                           // 科研产出
  autonomy: 0..3                                            // 授权度
  flags:   Set<string>                                      // 伏笔、支线、已解锁档案
  loadout: ModuleId[]; site: SiteId; presets: PresetId[]
  history: StepLog[]                                        // 用于结算页回放曲线
}
```

### 2.2 决策解析
- 每个决策选项都有**确定性效果**，并可附带**风险判定**（按概率表加修正项）。
- 随机数用带种子的生成器（mulberry32），种子在开局时生成，结算页会显示出来，方便复现。
- **信息滞后**：界面上显示的风险概率是一个区间（例如"18% 到 35%"），区间宽度由遥测延迟和已装备的探测类模块决定。实际概率在区间内取值，等延迟时间过去后才揭晓。
- 所有效果都会写进 `history`，结算页据此画出五维资源曲线，并标注"关键转折决策"。

### 2.3 三大标志机制（逐章教学）
1. **延迟时间戳**（序章教）：所有遥测和对话都标注"火星时间 T−xx 分钟"。
2. **预案卡**（第三章教，第四章复用）：在通信盲区（EDL、日凌）之前，从约 8 张卡里选 3 张"若……则……"规则。盲区内的随机故障按预案卡判定，没有覆盖到的故障交给乘员按授权度和信任度自行判断。
3. **授权度**（第四章教）：分 0 到 3 级。授权越高，乘员处理突发情况越快，但他们的自主决策可能违背你的偏好，结果取决于信任度；授权越低越可控，但每件事都要多等一个延迟周期。

### 2.4 失败与压力
- 硬失败（直接进入结局）：氧气或水的可维持天数降到 0、栖息舱完整度降到 0、上升器推进剂不足、乘员全部失联。
- 软压力：累计辐射剂量超过 600 mSv（NASA 2022 年的职业剂量上限）会触发健康事件；士气过低会引发违抗或抗命事件；信任度会影响授权的结果。

**着陆点**：
- 乌托邦平原（"祝融号"着陆区）：稳妥，有中等程度的冰。
- 杰泽罗撞击坑：科研加成高，但 EDL 难度高。
- 阿卡迪亚平原：浅层冰最丰富，但纬度高、光照弱。

**结局（7 个）**：满载而归、平安归来、留守者、代价、中止、寂静红土，以及隐藏结局「放手」（需要高信任、高授权，并解开导师线）。判定写在 `endings.ts`，是一组按优先级排列的谓词。

**数值目标**（用蒙特卡洛模拟验证）：
- 用随机加启发式策略跑一万局，"满载而归"占 15% 到 20%，失败类结局占 10% 到 15%。
- 三个着陆点乘以两种能源路线，每种组合都至少有一条路径能拿到 S 评级。
- 不能有任何单个模块或选项让胜率提升超过 25 个百分点（用来发现"最优解"漏洞）。

## 4. 叙事与对话

- **对话框 UI**（2026-10-07 改版，取代原来的通信频道列表，规格见 `docs/superpowers/specs/2026-10-07-550-ui-shell-design.md`）：3D 画面全屏，底部是 550 式对话框，一次只显示一句，打字机效果。采用"闸门"模型：显示下一句前，上一句必须先被确认；打字途中点一下只会补全整句，所以读完每句正好点一次。火星乘员的台词出现前，先显示"接收中 · 信号经 X 分钟抵达"，并带"火星时间 T−mm:ss"时间戳。决策提问作为一句台词出现在对话框里，选项卡片叠在对话框上方，可按数字键选择。A 键开关自动推进，L 键打开本局的"通信记录"。五维资源压缩成顶部状态条；完整遥测放在左侧抽屉里，点状态条或按 T 键打开。
- **对话数据格式**（`src/content/dialogue/*.ts`）：
  ```ts
  { id, speaker, text, delayTag?, voice?: 'ch2_017.mp3',
    when?: (s)=>boolean, effects?, choices?: [{ text, effects, next }] }
  ```
- **主线暗线**：秦岳在 2025 年指挥过一次无人着陆任务，因为过度干预导致失败。他的台词前五章逐步留下线索，第五章揭晓。玩家整局的平均授权度和信任度决定他的最后一句话。
- **支线一**：沃尔科夫医生隐瞒辐射造成的白细胞下降。如果第二章发现了，第四章会是可控结局；如果没发现，他会在第四章倒下。
- **支线二**：地面指挥部"周副主任"会不断施压，要求压缩安全冗余、提升科研产出。
- 写作规范：每章 30 到 60 句台词，每句不超过 40 字。关键句标记 `voice`，由 TTS 生成。

### 5.2 离线包的关键约束（`file://`）
- Chrome 在 `file://` 下会拦截 `type="module"` 脚本和 `fetch`，用本地图片做 WebGL 纹理也会被判为跨域。所以离线构建要用 **vite-plugin-singlefile** 把 JS 和 CSS 内联进单个 HTML，**纹理和高程数据以 base64 或二进制的形式内联**（目标总体积小于 25 MB）。
- 配音用 `HTMLAudioElement` 播放，它在 `file://` 下可用，音频文件放在 `voice/` 目录，不经过 WebAudio 解码。
- GitHub Pages 版本和离线版本使用同一份构建产物，以离线约束为准。
- 冒烟测试必须包含"直接打开离线包里的 `index.html`"这一项。

### 5.3 渲染要点
> 2026-10-08 起，场景实现按子项目 B 规格重做（`src/render/scenes/` 分文件、`director.ts` 镜头导演、`holo.ts` 全息标注），下列为原始方案。
- **轨道场景**：太阳、地球、火星，以及霍曼转移轨道，按时间推进展示窗口时机。
- **巡航场景**：飞船程序化建模，太阳粒子事件用粒子流加屏幕色偏表现。
- **EDL 场景**：等离子激波着色器，然后是降落伞、反推、扬尘；镜头脚本化。画面上叠加"延迟回放"的时间码。
- **地表场景**：MOLA 高程加 fBm 噪声生成地形；火星大气天空着色器（白天偏奶油黄，日落偏蓝）；沙尘暴用体积雾、粒子和光照衰减表现；基地模块按建站决策逐个出现。
- **画质三档**：高档开启阴影、SSAO、辉光、景深和胶片颗粒；中档只保留辉光和颗粒；低档关闭后期处理，地形网格降到四分之一。首次运行时测 2 秒帧率自动定档，之后可手动切换。
- 在 UI 叠层上显示科学信息：高程剖面图、太阳光照强度、剂量计、光学厚度。

### 5.4 依赖
three（含 examples 里的 postprocessing），vite，typescript，vite-plugin-singlefile，vitest，@playwright/test。**不使用任何运行时 API 或后端。**

## 6. 科学依据清单（第 0 个里程碑逐条核实，写入 SCIENCE.md，并注明"游戏简化值"和"真实值"）

- 地火发射窗口的周期（约 26 个月）和 2035 年窗口的具体日期，需要核实
- 霍曼转移所需时间（约 7 到 9 个月），合冲型任务的地表停留时间（约 450 到 550 天）
- 单程光速延迟（约 3 到 22 分钟），日凌通信中断的时长
- 好奇号 RAD 的巡航剂量率和往返总剂量（Zeitlin 等，《Science》2013 年）；NASA 职业剂量上限 600 mSv
- 火星表面太阳辐照度约 590 W/m²，约为地球的 43%；火星日（sol）长 24 小时 39 分
- Kilopower 和 KRUSTY 实验（2018 年），功率等级 1 到 10 kWe
- MOXIE 的产氧速率（最高约 12 g/h）
- 国际空间站环控生保系统的水回收率（约 98%）
- 萨巴蒂尔反应的方程式，就地生产甲烷和液氧推进剂的概念
- 2018 年全球沙尘暴（光学厚度 τ 超过 10，"机遇号"失联）
- EDL 约 7 分钟（好奇号和毅力号的公开资料）
- 乌托邦平原（"祝融号"，2021 年）、杰泽罗撞击坑（"毅力号"，2021 年）、阿卡迪亚平原（SWIM 浅层冰图）的位置、高程和冰分布
- "火星-500"实验（2010 到 2011 年，520 天隔离）
- 数据来源：NASA PDS 和 USGS Astrogeology（MOLA MEGDR，火星全球拼接图，均为公有领域）。**注意**：如果游戏里要用中国地图，必须使用标准地图服务网下载的带审图号版本；本游戏不使用任何地图；2026-10-08 起地球画面使用 NASA Blue Marble 卫星影像（无国界、无地名），经用户确认保留。

## 9. 验证方式

1. `npm run test`：Vitest 覆盖效果计算、结局谓词的全部分支、同一种子跑两遍结果完全一致、存档读写。
2. `npm run simulate -- --runs 10000`：输出结局分布表，检查是否达到 2.4 和第 3 节的数值目标。
3. `npm run e2e`：Playwright 在 1440×900 和 390×844 两种视口下，用固定种子从标题页走到结算页再点"再次挑战"；另外用 `file://` 打开离线构建产物，确认能跑通序章。
4. 在内置浏览器里手动试玩：分别用高档和低档画质；模拟 WebGL 失败，确认 2D 降级模式可以通关。
5. 部署后访问 GitHub Pages 链接，确认没有注册、没有外部请求（用网络面板检查），控制台没有报错。

## 10. 风险与注意事项

- **旧产物**：工作区里有未跟踪的 `dist/`、`releases/`、`test-results/`、`node_modules/`、`tsconfig.tsbuildinfo`。按你的要求**不读取它们**。M0 开始时我会先征求你的同意，把它们移到仓库外面或直接删除，然后重新 `npm install`，避免和新项目混在一起。
- **写实画面的工作量**：如果第 3 周超时，EDL 和沙尘暴的效果优先保留，轨道和巡航场景退回简化版。
- **离线包体积**：严格控制纹理分辨率，配音用 48 kbps 的 mp3。
- **科学数据的准确性**：所有数值都必须写明来源；做了简化的地方要明确标注。
- **AI 素材**：在 README 里如实说明哪些素材是 AI 生成的（立绘、配音），并写明所用工具。

## 11. 实施偏差
