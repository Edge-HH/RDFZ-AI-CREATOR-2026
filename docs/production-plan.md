# 灰环点火开发交付状态

## 当前实现

Vite + 原生 TypeScript + Three.js，数据驱动八次决策和四种结局。完整的简报→对话→三维观察→规划→执行→反馈→结算→重玩已经接通。

- 规则：资源上下限、负责人疲劳/专业效果、保障能源、路线选择、准备旗标、确定性事件、结局判定、重复提交与阶段保护。
- UI：科幻会话、当前/历史对白、资源与人员状态、行动缺口、风险预估、实际反馈、维修日志、结算趋势、帮助/暂停、下载记录。
- Three.js：共用地形、点选/键盘路线、车辆移动、本地 GLB、LOD、扫描无人机、中继圈、OrbitControls 与俯视/跟随；WebGL 回退等价二维路线图。
- 非正常状态：人员失去行动能力、资源短缺、通信盲区、刷新恢复、存储失败、隐藏/暂停、模型失败、WebGL 失败、减少动效。
- 交付：README、实际规则、资产说明、构建 dist、离线 ZIP、本地启动脚本、GitHub Pages 工作流。

## 验证

`npm test` 验证规则和合法结局可达性；`npm run test:e2e` 在桌面和小屏测试完整通关、资源分配、地图、刷新、暂停、键盘、触控、回退、本地模型加载和外部请求隔离。`TEST_DIST=1` 时同一测试使用生产构建和离线服务器。

截图存入 `releases/screenshots/`；Node / Python 离线启动说明在 README。帧率目标为桌面约 60、手机约 30，实际受设备影响，测试不冒充所有设备性能保证。
