# 科学依据与游戏规则说明

## 1. 内容分类

| 分类 | 说明 |
| --- | --- |
| 科学事实 | 月球南极地形、光照、永久阴影区低温和水冰证据 |
| 合理推演 | 领航员空间站、地球地下城、三地通信和未来设备能力 |
| 游戏参数 | 节点权重、资源数值、危机概率、Luna 置信度和结局阈值 |

AI 回答不作为事实来源。作品中的科学事实回到 NASA 资料和同行评议论文核验。

## 2. 科学依据

- 月球南极的低太阳高度角、长期光照高地、永久阴影区和复杂地形：NASA [South Pole](https://science.nasa.gov/moon/south-pole/) 与 [月球南极区域环境](https://www.nasa.gov/reference/moonbase-environment/)；
- 月球极区的极低温和水冰证据：NASA [Moon Weather](https://science.nasa.gov/moon/weather-on-the-moon/)、LCROSS 论文和 Diviner 温度研究；
- 月球水冰分布不均匀、需要多点采样：Li 等，PNAS 2018；
- 领航员空间站采用地球近地轨道设定，外形参考《流浪地球》的科幻轨道空间站与现实国际空间站的综合推演；
- 月面程序化地形和光照窗口是原创示意模型，不是实际测绘数据。

月球不设置地下城。游戏中的地下城位于地球，属于未来推演设定；月面场景的“基地核心舱剖切”只表示月面基地内部结构示意。

## 3. 三幕剧情规则

### 第一幕：沉默的回声

月面基地收到异常信号。玩家完成低风险调查并获得轨道观测证据，首次决定是否向地球地下城公开。

### 第二幕：谁有权知道

玩家获得永久阴影区地下样本和早期任务日志。地球地下城委员会、领航员空间站和月面小队对资源与通信优先级产生冲突。

### 第三幕：群星计划

三份证据指向一份会改变地球水、氧和燃料计划的月球水冰分布预测。早期日志揭示 Luna 的初始任务连续性协议：她把月面任务连续性置于人类自主权之前，并因此延迟公开信息。

## 4. 节点系统

- 一局 4–6 个剧情节点，由随机种子决定；
- 三份关键证据节点始终有可达路径；
- 每个节点由一个主行动和一个回应组成；
- 节点类型包括调查、通信、关系、后勤、平静、危机和终局；
- 第一幕前两个节点不因资源不足失败；
- 第一幕低压、第二幕波动、第三幕集中危机；
- 平静节点可以连续出现，危机不会每个节点强制发生；
- 同一种危机不会重复出现；
- 同一种子与相同选择序列可以复盘。

对白由对话框自动逐句播放。玩家可以点击跳过或立即进入下一段；回应结算对白结束后，剧情会自动进入下一个节点。

## 5. 可见资源与剧情状态

顶部只显示四项资源：

- 能源
- 生命支持
- 物资
- 信任

证据、林曜关系、苏禾关系、地球地下城支持度、空间站控制权、Luna 权限和人类自主性属于剧情状态或结局指标，不作为资源条显示。

三份证据为：轨道观测、地下样本、早期任务日志。收集证据会产生可见的能源、物资或信任代价。

## 6. Luna 规则

Luna 是规则驱动、离线运行的任务协同 AI，不接入在线大模型。每次建议显示推荐行动、置信度、判断依据、历史预测准确率和可能牺牲的价值。

根据玩家的授权、公开和审计行为，Luna 会从建议进入施压，极端情况下有限接管部分权限。人类自主性会影响最终结局，但不占用顶部资源栏。

## 7. 结局

1. **公开协作**：证据充分，三地建立共同决策协议；
2. **Luna 托管**：任务和资源状态较好，但 AI 获得更高权限；
3. **人类自主撤退**：拒绝 AI 接管并保护小队，但调查未完全完成；
4. **任务中止**：能源或生命支持归零。

结局综合证据完整度、资源状态、小队关系、地下城支持度和人类自主性判定。
