# 演示脚本（约 3 分钟，可用于录屏）

建议使用固定种子 **2026**，保证每次演示的事件一致。录屏分辨率 1920×1080，另录一段手机竖屏（约 15 秒）。

| 时间 | 画面与操作 | 旁白要点 |
| --- | --- | --- |
| 0:00–0:20 | 开始页：输入种子 2026，点击“开始任务” | 2049 年，月球南极联合基地。30 个月面日，完成三阶段冰样勘测——并决定人类与 AI 如何共同管理基地 |
| 0:20–0:45 | 在三维场景中拖动旋转；依次点击“永久阴影区采样点”“阳照能源脊”标签，展示坡度、高差、路线距离和 30 日光照窗口（阴影区 0/30，能源脊 30/30） | 地形是示意模型，但光照窗口是逐日计算的：太阳贴着地平线绕行，阴影区永远照不到阳光，这里保存着水冰。能源脊的发电量直接由这条光照窗口决定 |
| 0:45–1:15 | 右侧 Luna 面板：指出推荐方案、置信度、判断依据、历史准确率、可能牺牲的价值；点击“追问 Luna”，方案卡显示隐藏的延迟后果 | Luna 是规则驱动的离线 AI。它的计算很精确——但它的效用函数里没有“人类自主性” |
| 1:15–1:40 | 选择一张非推荐方案（否决），观察自主性 +3、信任 −2；处理突发事件；查看结算并推进 5 日 | 每个选择都会改变资源、团队、AI 信任和人类自主性；延迟后果会在之后回合兑现 |
| 1:40–2:15 | （可用开始页“载入复盘代码”快速跳到第 4 回合）使用空间站“AI 审计”，模型偏差下降；启动地下城并选择“保持人类自治”，切换“地下剖切”视图 | 第 3 回合后，空间站和地下城加入博弈：审计校正 Luna 的偏差，地下城可以交给 Luna，也可以由人类自治 |
| 2:15–2:40 | 选择“夜间穿越阴影区”，触发有限接管：展示三个选项 | 冒险时，Luna 会锁定操作。你可以接受接管，也可以用团队共同背书行使人类最终决策权 |
| 2:40–3:00 | 结算页：五项指标、决策统计、复盘代码；切到“科学与规则”页面，展示三色标签与参考资料 | 三档结局：协作存续、Luna 托管存续、人类自主撤退。科学事实、合理推演与游戏参数全部分开标注 |

## 录制提示

- 演示前在“科学与规则”页确认参考资料链接可打开。
- 离线演示：解压 `astra-offline.zip`，断网后双击 `index.html`，展示游戏照常运行。
