# 光速之隔 · 火星首航

> 2035 年，人类第一次载人火星任务。你是地球上的飞控总师。
> 火星上的每一句话，传到你耳边都要十几分钟。**你看到的一切，都是过去。**

《光速之隔》是一款以**首次载人火星任务**为背景的策略叙事网页游戏，参赛方向为 2026 校园 AI 创作者大赛 · 项目 3 策略游戏 · 时代征程【未来推演】。玩家要在**时间、能源、物资、人员、安全**五类限制下配置资源、选择方案、判断风险，把四名乘员送上火星，再把他们带回来。

- **在线游玩**：<https://edge-hh.github.io/RDFZ-AI-CREATOR-2026/>（由 GitHub Actions 自动部署）

## 怎么玩

### 你的身份

你是北京航天飞控中心的总师。退休的老总师秦岳把椅子交给你。四名乘员是：指令长林照、工程师阿玛拉、医生沃尔科夫、地质学家早川凛。

### 流程

| 章节 | 发生什么 | 新学的机制 |
|---|---|---|
| 序章 · 交接班 | 向火星中继星发一条指令，亲眼看它在延迟之后才得到回音 | 光速延迟 |
| 第一章 · 窗口 | 12 个槽位配载约 18 种模块；三个着陆点选一；决定发射日是否推迟 | 取舍 |
| 第二章 · 深空 | 259 天巡航：太阳粒子事件、水回收故障、隔离心理危机 | 在旧信息下判断风险 |
| 第三章 · 恐怖七分钟 | 着陆只有 7 分钟，信号却要走 13 分钟。着陆前写下 3 张预案卡 | 预案卡 |
| 第四章 · 红土 | 454 天驻留：建站、采样、全球沙尘暴、两周日凌、医生的秘密 | 授权度 |
| 第五章 · 归途 | 推进剂缺口怎么补，谁回家、谁留下，老秦十年前的真相 | 最终抉择 |

### 五维资源（跨章延续）

- **时间**：发射窗口、返程窗口、日凌。
- **能源**：发电与需求、储能。沙尘暴会让太阳能输出跌到约 6%。
- **物资**：氧气、水、食物（以“可维持天数”计），以及备件。
- **人员**：每名乘员的健康、士气，以及对你的信任。
- **安全**：系统完好度，以及累计辐射剂量（上限 1000 mSv）。

### 三个核心机制

1. **信息滞后**：风险显示为一个区间，例如“估计 18% ~ 35%”。延迟越久、预警设备越少，区间越宽。
2. **预案卡**：通信盲区里，有预案的故障按预案处理；没有预案的，交给乘组临场判断。
3. **授权度（0–3）**：放手越多，乘组越果断，盲区里的自主处置越可能成功，但他们也可能做出你不认同的决定；授权过低则事事要等一个通信往返，士气会下降。

### 结局

一共 7 个结局：**满载而归、平安归来、留守者、代价、中止、寂静红土**，外加一个隐藏结局。结局按“乘员状态 × 科研产出 × 是否返回”判定，另有 S–D 综合评级（科研 40、健康 30、辐射 15、信任 15）。

叙事模式下资源消耗与负面影响减半，适合只想体验剧情的玩家。

### 知识档案集

每次做出相关决策或取得科研进展，都会弹出一张**知识档案卡**，附来源和原始链接（DOI 或官方机构页面）。档案会跨局保存，随时可以在顶栏查看。目前共 22 张。

## 运行与开发

需要 Node.js 22 或更高版本。

```bash
npm install
```

```bash
npm run dev
```

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地开发服务器 |
| `npm test` | 单元测试（Vitest）：轨道、资源、风险、结局、流程、全内容自动通关 |
| `npm run simulate -- --runs 4000` | 蒙特卡洛平衡测试，输出结局分布和各模块的影响 |
| `npm run e2e` | 端到端测试（Playwright，使用系统已安装的 Chrome）：桌面与手机通关、读档、零外部请求、离线包 |
| `npm run build` | 构建单文件 `dist/index.html` |
| `npm run package` | 打包 `release/光速之隔-离线版.zip` |

URL 参数（调试用）：`?seed=123` 固定随机种子，`?fast=1` 跳过对话动画。

### 目录

```
src/core/      纯逻辑：轨道、状态、效果、速率、时间推进、风险、盲区结算、结局、流程（不依赖 DOM 和 three）
src/content/   全部数据：章节剧本、模块、着陆点、预案卡、科学档案、结局文本
src/render/    three.js：六类场景、程序化贴图、画质分档与 2D 降级
src/ui/        界面：状态条与遥测抽屉、逐句对话框与通信记录、取景框、决策弹窗、结算与档案
src/audio/     WebAudio 合成音效、配音播放
src/sim/       自动游玩（测试与平衡共用）
tests/ e2e/    单元测试与端到端测试
```

## AI 使用说明

- **策划与开发**：游戏策划（经多轮问答敲定）、剧本、数值模型、代码和测试都在 AI 编程助手 Claude Code 的协助下完成。作者负责全部决策，并逐项审核科学数据。
- **美术**：火星与地球表面使用 NASA 公有领域影像：火星为 NASA 3D Resources 的 Mars 贴图（NASA/JPL-Caltech，Viking 影像经 USGS 处理），地球为 NASA Earth Observatory 的 Blue Marble: Next Generation（2004 年 12 月，地形与海底地形版，无国界与地名）。两张贴图由 `scripts/prep-textures.py` 缩放后内联进离线包。云层、地形、天空、航天器与基地模型全部由代码程序化生成。人物图像由 GPT Images 2.5 生成（配音由 XiaomiMimo 2.5 TTS 生成）。8 张角色头像使用 Codex 内置图片生成工具制作，采用与 550 风格界面搭配的像素画；整理为 64×64、最多 24 色，再以最近邻放大到 256×256 PNG，保存在 `src/assets/portraits/`。550A 保留程序绘制的红眼。提示词和处理方法见 [docs/PROMPTS.md](docs/PROMPTS.md)。
- **配音（可选）**：关键台词清单见 [docs/voice-lines.json](docs/voice-lines.json)。已用 MiMo TTS 生成慢、中、快三套录音，放在 `public/voice/<slow|mid|fast>/<编号>.mp3`。配音默认关闭，可在设置中开启并切换语速（默认中速）；文件缺失时游戏照常运行。
- **音效**：全部由 WebAudio 实时合成，没有版权风险。

## 隐私与声明

- 不需要注册或登录，不收集任何个人信息。存档和档案只保存在你自己的浏览器（localStorage）里。
- 运行时不发出任何网络请求。知识档案里的外部链接只有在你点击时才会打开。
- 人物、“燧火计划”“远航一号”等情节均为虚构。本游戏不使用任何地图（无国界、无行政区划、无地名）；火星与地球画面仅使用 NASA 公有领域卫星影像，地球影像不含国界和地名。
- 量子计算工程样机“550A-Preview”和营地的四足机器人“笨笨”，是向电影《流浪地球》系列致敬的彩蛋，名称归原作品所有；相关台词均为原创。
