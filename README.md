# 灰环点火

公网版本：[启动灰环点火](https://edge-hh.github.io/RDFZ-AI-CREATOR-2026/)

原创科幻策略叙事网页。玩家作为现场系统工程师林岑，与五人小队运送脉冲点火芯、穿越白弧盆地并抢修环弧—7 行星推力塔。

## 运行

源码需要 Node.js 22.12 或更高版本：

```sh
npm ci
npm run dev
```

开发地址是终端显示的本地地址。生产构建与预览：

```sh
npm run build
npm run preview
```

核心玩法无需登录、个人信息、API 密钥、外部模型 CDN 或运行时私有接口。源码安装依赖需要网络，构建后所有 JS、模型和图标已打包在本地。

## 离线包

```sh
npm run package:offline
```

输出 `releases/gray-ring-ignition-offline.zip`，每次打包重新生成同名目录，避免旧构建混入。解压后，在 Windows 双击 `start-local.bat`，它用已安装的 Node.js 或 Python 3 启动本地服务器。也可以在包目录手动运行 `node serve.mjs`，访问 `http://127.0.0.1:4173/`。服务器仅绑定本机，断网仍能完成一局。没有 Node/Python 的评审机需要先安装其中一个；不默认保证直接双击 `index.html` 的 ES 模块环境可运行。

## 怎么玩

主线：将点火芯送达环弧—7，并完成推力塔重启。主屏显示这条主线和当前要完成的具体任务。

1. 点“继续对话”，逐句听队员报告。听完本段通信后才出现你的回应。
2. 选择林岑的回应，查看这次行动的实际代价与风险。可以重新选择，确认前不会扣资源。
3. 需要时展开“调整保障与负责人”，分配 0/4/8 能源或指定专业成员；默认值也能完成行动。
4. 确认回应并行动，收到对应的队员回传和真实资源变化，再点“继续剧情”。
5. 到达塔下完成最终点火或撤离，查看四类结局和维修记录，可重新挑战。

八项任务依次是出发检查、装载、路线、险阻处置、链路保障、预校准、磁腔维修、点火。南坡与西沟带来不同对白、耗时、能源和后续风险。能源供车辆、通信和点火共用；保障系统降低风险但消耗后段预算，负责人会积累疲劳。

## 辅助信息、控制与恢复

- 对话下方按需打开“态势图”“资源与队员”“通信记录”。返回对话后继续同一句，辅助面板不会跳过剧情。
- 态势图首次打开时加载 Three.js 本地模型，关闭后停止渲染；拖动旋转、滚轮缩放，支持俯视与跟随。
- 选择南坡/西沟的对话回应会同步选中地图路线；也可先在图上核验距离、坡度、温度、横风与通信置信度。
- Tab/Enter 操作；听完通信后可用 1–4 选回应；Esc 暂停或关闭当前面板；R 重置视角。画布方向键选择节点、Enter 确认。
- WebGL 不可用时使用二维路线图，`?fallback=1` 可测试回退；不开地图也能完成全部剧情与策略流程。
- 菜单提供帮助、声音开关、主动撤离。声音默认关闭，开启后使用原创合成音效。
- 进度只存本机 localStorage，包含已经读到的对白和待确认回应。刷新可恢复，禁用存储仍能玩；兼容上一版存档。
- 支持手机、平板、桌面与系统减少动态效果设置，不上传个人数据。

## 科学与资产

行星迁移、行星推力塔、脉冲点火芯是原创未来假设。NASA/ESA 资料只用于热管理、地形移动、生命保障与通信视距的概念约束；参数不是工程设计依据。参见 `docs/science-and-rules.md`。

三维无人设备示意采用 NASA/JPL-Caltech Perseverance 模型的本地优化版；它不代表现实载人车。发动机、无人机、SVG 图标及音效为项目原创。来源、修改和使用说明见 `public/assets/LICENSES.md`。本作不使用《流浪地球》角色、台词、原画、音乐或专有模型。

## 检查与发布

```sh
npm test
npm run test:e2e
npm run build
```

浏览器测试默认使用已安装 Chrome；CI 可设置 Playwright Chromium。规则测试覆盖重复提交、暂停、错误阶段、资源短缺、专业与保障分配、路线分支、相同种子复盘、所有结局的合法可达性。

`.github/workflows/pages.yml` 提供 GitHub Pages 构建部署，构建产物可用于任意静态服务器。当前仓库 Pages 环境只允许 main 分支发布，功能分支不会自动替换线上站点。

性能目标：桌面约 60 FPS、移动端约 30 FPS。帧率受设备/浏览器/WebGL 驱动影响；小屏限制 DPR 为 1.5，持续低帧率时降低 DPR 并使用低模，隐藏/暂停停止渲染。执行计时独立于渲染帧率。目标不是对所有设备的保证。
