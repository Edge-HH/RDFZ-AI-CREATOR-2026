# 灰环点火

公网版本：https://edge-hh.github.io/RDFZ-AI-CREATOR-2026/ （发布完成后可访问）

原创科幻策略叙事网页。玩家作为现场系统工程师林岑，与五人小队运送脉冲点火芯、穿越白弧盆地并抢修环弧—7 行星推力塔。

## 运行

源码需要 Node.js 22.12 或更高版本：

```sh
npm ci
npm run dev
```

开发地址是终端显示的本地地址。生产构建与预览：

```sh
npm run build
npm run preview
```

核心玩法无需登录、个人信息、API 密钥、外部模型 CDN 或运行时私有接口。源码安装依赖需要网络，构建后所有 JS、模型和图标已打包在本地。

## 离线包

```sh
npm run package:offline
```

输出 `releases/gray-ring-ignition-offline.zip`。解压后，在 Windows 双击 `start-local.bat`，它用已安装的 Node.js 或 Python 3 启动本地服务器。也可以在包目录手动运行 `node serve.mjs`，访问 `http://127.0.0.1:4173/`。服务器仅绑定本机，断网仍能完成一局。没有 Node/Python 的评审机需要先安装其中一个；不默认保证直接双击 `index.html` 的 ES 模块环境可运行。

## 怎么玩

1. 读通信，先知道谁在报告什么。
2. 在态势窗或路线按钮选择南坡/西沟；查看距离、坡度、温度、横风与通信置信度。
3. 选行动卡，分配 0/4/8 能源给保障系统，指定一名负责人。
4. 看真实成本、前置条件和风险预估，确认后行动不可撤销。
5. 执行后看资源差值、人员健康/疲劳和队员反馈，再进入下一段通信。
6. 到达塔下完成点火，结算四种结局；也可主动撤离并保留记录。

任务是八次主要决策：出发检查、装载、路线、险阻处置、链路保障、预校准、磁腔维修、点火。不是连续点击或知识问答。能源供车辆、通信和点火共用，保障系统降低风险但消耗后段预算。负责人会累积疲劳，专业匹配会改变校准/地形/通信结果。

## 控制与恢复

- 鼠标/触摸点击；三维窗拖动旋转、滚轮缩放；有重置、俯视、跟随按钮。
- Tab/Enter 操作；1–4 选择行动；Esc 暂停；R 重置视角。画布方向键选择节点、Enter 确认。
- 手机点“展开”显示态势窗，所有路线也有文字按钮。
- WebGL 不可用时自动切换二维；`?fallback=1` 可手动测试回退。
- 进度仅存本机 localStorage，不上传。刷新后可选择恢复；禁用存储时仍可玩。
- 默认静音，开启声音后使用原创合成音效。
- 支持系统的减少动态效果设置。

## 科学与资产

行星迁移、行星推力塔、脉冲点火芯是原创未来假设。NASA/ESA 资料只用于热管理、地形移动、生命保障与通信视距的概念约束；参数不是工程设计依据。参见 `docs/science-and-rules.md`。

三维无人设备示意采用 NASA/JPL-Caltech Perseverance 模型的本地优化版；它不代表现实载人车。发动机、无人机、SVG 图标及音效为项目原创。来源、修改和使用说明见 `public/assets/LICENSES.md`。本作不使用《流浪地球》角色、台词、原画、音乐或专有模型。

## 检查与发布

```sh
npm test
npm run test:e2e
npm run build
```

浏览器测试默认使用已安装 Chrome；CI 可设置 Playwright Chromium。规则测试覆盖重复提交、暂停、错误阶段、资源短缺、专业与保障分配、路线分支、相同种子复盘、所有结局的合法可达性。

`.github/workflows/pages.yml` 提供 GitHub Pages 构建部署，构建产物可用于任意静态服务器。当前仓库 Pages 环境只允许 main 分支发布，功能分支不会自动替换线上站点。

性能目标：桌面约 60 FPS、移动端约 30 FPS。帧率受设备/浏览器/WebGL 驱动影响；小屏限制 DPR 为 1.5，远景使用低细节表示，隐藏/暂停停止渲染。目标不是对所有设备的保证。
