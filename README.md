# 《Astra:群星计划》

> 月面异常信号 · 三地通信决策 · 策略叙事网页游戏（Three.js）

玩家扮演月面基地任务指挥官，调查来自永久阴影区附近的异常信号。地球地下城、领航员空间站和月面小队会对资源、证据和权限提出不同要求。

- **在线游玩**：<https://edge-hh.github.io/RDFZ-AI-CREATOR-2026/>
- **离线版**：运行 `npm run package:offline` 生成 `release/astra-offline.zip`

## 玩法

| 内容 | 规则 |
| --- | --- |
| 剧情结构 | 三幕：沉默的回声 → 谁有权知道 → 群星计划 |
| 一局长度 | 4–6 个剧情节点，由随机种子决定 |
| 节点流程 | 对话框自动播放剧情；一个主行动 + 一个回应；结算对白后自动进入下一节点 |
| 核心资源 | 能源、生命支持、物资、信任 |
| 关键证据 | 轨道观测、地下样本、早期任务日志，三份均有可达路径 |
| 三地舞台 | 月面基地、领航员空间站、地球地下城 |
| 风险节奏 | 第一幕低压，第二幕波动，第三幕集中危机；平静节点不会强制触发灾难 |
| AI | Luna 提供建议、依据、置信度和权限干预，不依赖在线大模型 |
| 结局 | 公开协作、Luna 托管、人类自主撤退、任务中止 |

月球不设置地下城。场景中的“剖切”只表示月面基地核心舱的结构示意；地球地下城通过通信场景、后方决策和资源支持参与剧情。

## 本地开发

需要 Node.js 22+。

```bash
npm install
npm run dev
```

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动本地开发服务器 |
| `npm test` | 运行节点流程、随机性、证据必达、结局和 Luna 建议测试 |
| `npm run typecheck` | 只运行 TypeScript 类型检查 |
| `npm run build` | 类型检查并构建在线版到 `dist/` |
| `npm run package:offline` | 构建单文件离线版并打包到 `release/astra-offline.zip` |

## 目录结构

```text
src/
  data/storyNodes.ts  三幕剧情节点、支线和选择后果
  engine/              可复盘的纯 TypeScript 状态机
  story/               渐进式新手引导、通信对白和结局对白
  world/               月面示意地形、坡度、路线和光照
  scene/               Three.js 月面、空间站和基地核心舱剖切
  ui/                  资源、证据、关系、通信和节点操作面板
tests/                 Vitest 规则与随机性测试
docs/                  科学依据、创作说明、素材披露和演示文档
```

## 科学与隐私

月面地形、极区光照、永久阴影区和水冰证据参考公开 NASA 资料与同行评议论文。信号、Luna 协议、地球地下城和节点数值属于合理推演或游戏参数，界面与文档会明确区分。

游戏不要求注册或登录，不收集个人信息，不依赖私有 API 或在线大模型；不支持 WebGL 时，规则和决策界面仍可使用。
